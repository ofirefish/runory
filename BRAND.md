# Runory Brand / VI Specification

## 1. Brand Name

**Runory**

Recommended pronunciation:

> RUN-uh-ree

The name is intentionally broader than SSH or Terminal so the product can expand into infrastructure operations.

## 2. Brand Idea

Runory combines:

- Run
- Remote Operations
- Infrastructure Movement
- Connected Nodes
- Control from Anywhere

## 3. Brand Promise

> Run your infrastructure from anywhere.

Runory should make server access and operations feel immediate, safe and coherent across devices.

## 4. Brand Attributes

Primary:

- Reliable
- Modern
- Precise
- Secure
- Calm
- Capable

Secondary:

- Intelligent
- Mobile
- Efficient
- Developer-friendly

Avoid:

- Hacker cliché
- Cyberpunk overload
- Server-rack clip art
- Terminal prompt as the only identity
- Generic AI sparkle imagery

## 5. Logo Concept

Primary symbol:

An abstract capital **R** with a connected-node detail and a sense of forward movement.

Meaning:

```text
R
+
Connection
+
Movement
+
Infrastructure Node
=
Runory
```

The logo must remain recognizable:
- at 20–24 px
- in desktop title bars
- as a mobile app icon
- as a favicon
- in monochrome
- on dark and light surfaces

## 6. Logo Variants

Required production variants:

1. Gradient symbol
2. Solid dark symbol
3. Solid white symbol
4. Horizontal symbol + Runory wordmark
5. Vertical app/splash lockup
6. Monochrome optical-size small mark

## 7. Clear Space

Use one internal stem width of the R symbol as minimum clear space on all sides.

Do not place:
- text
- border
- competing icons

inside the clear-space zone.

## 8. Minimum Size

Guidance:

```text
Symbol UI minimum         20–24 px
Horizontal lockup         ~120 px
Favicon                   dedicated optical-size export
```

## 9. Brand Colors

### Runory Blue

```text
#2563EB
```

Role:
- primary accent
- selected control
- link
- main brand presence

### Runory Cyan

```text
#06B6D4
```

Role:
- connection / flow accent
- gradient transition

### Runory Violet

```text
#7C3AED
```

Role:
- optional secondary accent

### Runory Green

```text
#10B981
```

Role:
- connected / success state
- optional gradient endpoint

## 10. Gradient

Preferred:

```css
linear-gradient(
  135deg,
  #2563EB 0%,
  #06B6D4 65%,
  #10B981 100%
)
```

Campaign graphics may use a blue-violet alternative, but the product UI should remain calmer.

## 11. Typography

Primary:
- Inter

Terminal:
- JetBrains Mono

The final Runory wordmark may receive custom optical adjustments while staying compatible with Inter-like UI typography.

## 12. Illustration / Photography

Prefer:
- abstract infrastructure topology
- subtle network lines
- real product screenshots
- restrained technical environments

Avoid:
- hooded hacker stock images
- generic glowing server rooms
- floating code rain
- humanoid AI robots

## 13. Icon Style

- Lucide-like outline
- 1.75–2px stroke
- simple geometry
- rounded line endings
- consistent outline language

## 14. Product Branding

Brand color should not dominate the terminal.

Use brand for:
- logo
- selected navigation
- primary CTA
- active items
- focused controls

Operational state uses semantic colors.

## 15. Voice

English:
- concise
- factual
- confident
- technically literate
- low-hype

Preferred:

> Connection lost. Reconnect to continue.

Avoid:

> Oops! Something super unexpected happened!

Chinese:
- 简洁
- 技术准确
- 克制
- 不堆感叹号

## 16. Message Hierarchy

Primary:

> Run your infrastructure from anywhere.

Secondary:

> One secure workspace for SSH, files, servers and operations.

Future AI:

> Diagnose faster. Execute with control.

Before AI becomes a mature feature, do not make “AI” the primary brand promise.

## 17. Product Naming

Possible future modules:

```text
Runory Desktop
Runory Mobile
Runory Terminal
Runory Files
Runory Vault
Runory Monitor
Runory AI
```

The main product should usually remain simply “Runory”.

## 18. App Icon

App Icon:
- use R symbol
- no small text
- no tiny decorative topology line
- strong silhouette
- works in dark/light launcher contexts
