# Operating system logo sources

The SVG files in this directory are vendored build assets. Runory never fetches them at runtime.

## Simple Icons

Nineteen distribution marks come from the fixed npm release `simple-icons@16.21.0`:

`almalinux`, `alpinelinux`, `apple`, `archlinux`, `centos`, `debian`, `fedora`, `freebsd`, `gentoo`, `kalilinux`, `linux`, `linuxmint`, `manjaro`, `nixos`, `opensuse`, `redhat`, `rockylinux`, `ubuntu`, and `voidlinux`.

The Amazon Linux mark uses `amazonwebservices.svg` from `simple-icons@14.15.0`, matching the AWS mark used by the Amazon-maintained Docker Official Image documentation.
